# ESP32 노드 배선도

노드 3개는 각자 USB로 전원을 받고, Wi-Fi + MQTT로 Pi5 MN-CSE에 데이터를 보낸다. Pi5와 ESP32 사이에는 선이 없다.

| 노드 | 보드 | 센서 |
|---|---|---|
| BRIDGE | ESP32-S3 | GPS, MPU6050 |
| ENGINE | ESP32-WROOM-32E | ADXL345, MQ-2 |
| CARGO | ESP32-C6 | DHT11, MC-38 |

공통 규칙
- 센서 GND는 모두 해당 ESP32의 GND에 연결한다.
- 3.3V 센서는 `3V3` 핀, 5V가 필요한 센서는 `5V`(WROOM은 `VIN`) 핀에 연결한다. 5V 핀은 USB 전원이 연결돼 있을 때만 5V가 나온다.

---

## 1. BRIDGE: ESP32-S3

### GPS 모듈 (NEO-6M 계열), UART1
| GPS 핀 | ESP32-S3 |
|---|---|
| VCC | 5V |
| GND | GND |
| TX | **GPIO18** (RX1) |
| RX | **GPIO17** (TX1), 선택 사항(설정 변경할 때만 필요) |

- 통신 속도는 9600bps(기본값)
- 실내에서는 위성 신호를 못 잡을 수 있다. 창가나 야외에서 테스트한다. 처음 위성을 잡는 데 수 분 걸릴 수 있다.

### MPU6050 (GY-521), I2C 주소 0x68
| MPU6050 핀 | ESP32-S3 |
|---|---|
| VCC | 3V3 |
| GND | GND |
| SDA | **GPIO8** |
| SCL | **GPIO9** |
| AD0 | GND (주소 0x68) |
| INT, XDA, XCL | 연결 안 함 |

- 보트에 고정할 때 X축을 선수 방향으로 맞추고, 수평으로 단단히 고정한다. 롤과 피치 기준이 된다.

---

## 2. ENGINE: ESP32-WROOM-32E

### ADXL345 (GY-291), I2C 주소 0x53
| ADXL345 핀 | ESP32-WROOM |
|---|---|
| VCC | 3V3 |
| GND | GND |
| SDA | **GPIO21** |
| SCL | **GPIO22** |
| CS | 3V3 (I2C 모드로 고정) |
| SDO | GND (주소 0x53) |
| INT1, INT2 | 연결 안 함 |

- 모터 근처 선체에 단단히 붙인다. 들떠 있으면 진동 값이 부정확하다.

### MQ-2 가스센서 (아날로그 출력), 분압 필요
| MQ-2 핀 | 연결 |
|---|---|
| VCC | **VIN (5V)** |
| GND | GND |
| AO | 분압 회로를 거쳐 **GPIO34** |
| DO | 연결 안 함 (원하면 GPIO35) |

분압 회로 (AO 최대 5V를 3.3V로 낮춤):
```
MQ-2 AO ──[10kΩ]──┬── GPIO34
                  │
                [20kΩ]
                  │
                 GND
```
- **AO를 GPIO34에 바로 꽂지 말 것.** 최대 5V가 들어와 ESP32가 손상될 수 있다.
- 20kΩ이 없으면 10kΩ 2개를 직렬로 연결한다.
- GPIO34는 ADC1 채널이라 Wi-Fi를 켠 상태에서도 아날로그 값을 읽을 수 있다. ADC2 핀(GPIO0, 2, 4, 12~15, 25~27)은 Wi-Fi와 동시에 쓸 수 없다.
- 새 센서는 처음 24시간 정도 전원을 켜 두면(번인) 값이 안정된다. 평소에도 켠 뒤 1~2분은 예열 시간이 필요하다.
- 히터가 약 150mA를 쓰고 뜨거워진다. 다른 부품에 닿지 않게 둔다.

## 3. CARGO: ESP32-C6

### DHT11
| DHT11 핀 | ESP32-C6 |
|---|---|
| VCC | 3V3 |
| GND | GND |
| DATA | **GPIO4** |

- 기판에 붙은 3핀 모듈은 풀업 저항이 내장돼 있다. 센서만 있는 4핀 제품이면 DATA와 3V3 사이에 10kΩ 풀업을 단다.
- 2초 이내 간격으로 다시 읽으면 오류가 난다.

### MC-38 도어센서 (A접점), 도착 전
| MC-38 선 | ESP32-C6 |
|---|---|
| 선 1 | **GPIO5** |
| 선 2 | GND |

- 극성이 없어서 두 선을 바꿔 연결해도 된다. 펌웨어에서 내부 풀업(`INPUT_PULLUP`)을 쓰므로 저항은 필요 없다.
- 도착 전에는 GPIO5에 점퍼선을 꽂고 GND에 댔다 뗐다 하면 해치 열림/닫힘을 흉내 낼 수 있다.
- 자석을 적재함 뚜껑에, 스위치 본체를 선체 쪽에 붙인다. 닫혔을 때 둘 사이 간격은 1cm 이내로 둔다.

## 피해야 할 핀
- **ESP32-S3**: GPIO0, 3, 45, 46(부팅 설정 핀), GPIO19, 20(USB), GPIO26~37(플래시/PSRAM 연결용, 보드에 따라 다름)
- **ESP32-WROOM-32E**: GPIO0, 2, 5, 12, 15(부팅 설정 핀), GPIO6~11(플래시)
- **ESP32-C6**: GPIO8, 9, 15(부팅 설정 핀), GPIO12, 13(USB), GPIO24~30(플래시)

## 배선 후 확인
1. 전원을 켜기 전에 VCC와 GND가 바뀌지 않았는지, 5V가 3.3V 센서에 들어가지 않았는지 확인한다.
2. MQ-2 분압을 멀티미터로 확인한다. GPIO34 쪽 전압이 3.3V를 넘지 않아야 한다.
3. I2C 센서는 I2C 스캐너 예제로 주소(0x68, 0x53)가 보이는지 확인한다.
